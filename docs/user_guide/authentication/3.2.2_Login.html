3.2.2 Login

The purpose of this workflow is to allow the Guest to log into an existing account on the system.

Execution steps:

Step 1: The Guest accesses the login page.

Step 2: The Guest inputs information:

  • Username or Email: The registered username or email address associated with the account.
  • Password: The password for the account.
