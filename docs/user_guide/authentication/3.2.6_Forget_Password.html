3.2.6 Forget Password

The purpose of this workflow is to allow the Guest to reset their account password if they have forgotten it.

Execution steps:

Step 1: The Guest accesses the Forgot Password page.

Step 2: The Guest inputs information:

  • Email Address: The verified email address associated with the account. This field is required.

Step 3: The Guest clicks the Send OTP Code button to receive the verification code and navigate to the Verify OTP page.

Step 4: The Guest inputs information:

  • Enter OTP Code: The 6-digit OTP code received in the email. This field is required.

Step 5: The Guest clicks the Verify OTP button to navigate to the Reset Password page.

Step 6: The Guest inputs information:

  • New Password: The new password for the account. This field is required.
  • Confirm Password: The confirmation of the new password. This field is required and must exactly match the new password.
