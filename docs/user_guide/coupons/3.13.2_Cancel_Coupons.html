3.13.2 Cancel Coupons

The purpose of this workflow is to allow the User to remove an applied discount coupon from a course in their shopping cart and revert to the original price.

Execution steps:

Step 1: The User navigates to the Cart page containing a course with an applied coupon.

Step 2: The User clicks the Remove button next to the applied coupon code to open the Remove Coupon modal.
