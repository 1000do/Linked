3.13.1 Apply Coupons

The purpose of this workflow is to allow the User to apply a discount coupon to a specific course in their shopping cart.

Execution steps:

Step 1: The User navigates to the Cart page with items added.

Step 2: The User inputs information in the coupon area of a specific course:

  • Enter coupon code: The valid coupon code to apply a discount. This field is required.
