3.13.7 Search Coupons

The purpose of this workflow is to allow the Admin to quickly search for specific discount coupons by their campaign codes.

Execution steps:

Step 1: The Admin accesses the Manage Coupons page.

Step 2: The Admin inputs information in the search area:

  • Search campaign codes...: The keyword used to search for specific discount campaigns. This field is optional.
