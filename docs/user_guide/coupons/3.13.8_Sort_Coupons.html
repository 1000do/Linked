3.13.8 Sort Coupons

The purpose of this workflow is to allow the Admin to sort the list of discount coupons based on various criteria such as date created, discount amount, or expiration.

Execution steps:

Step 1: The Admin accesses the Manage Coupons page.

Step 2: The Admin inputs information in the sort area:

  • Sort dropdown: The criteria used to sort the coupons list (e.g., Date Created: Newest, Discount: High to Low, Expiring Soon). This field is optional.
