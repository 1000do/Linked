3.13.9 Filter Coupons

The purpose of this workflow is to allow the Admin to filter the list of discount coupons based on their status or discount type.

Execution steps:

Step 1: The Admin accesses the Manage Coupons page.

Step 2: The Admin inputs information in the filter area:

  • Filter dropdown: The criteria used to filter the coupons list (e.g., Active, Paused, Percentage (%), Fixed ($)). This field is optional.
