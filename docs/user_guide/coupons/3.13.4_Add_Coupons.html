3.13.4 Add Coupons

The purpose of this workflow is to allow the Admin to create a new discount coupon and add it to the system.

Execution steps:

Step 1: The Admin accesses the Manage Coupons page.

Step 2: The Admin clicks the Create Coupon button to open the Configure Promotion modal.

Step 3: The Admin inputs information:

  • Campaign Promo Code: The unique code for the discount campaign. This field is required.
  • Discount Type: The type of discount (Percentage or Fixed Value). This field is required.
  • Discount Value: The numerical value of the discount. This field is required.
  • Start Date: The date the coupon becomes valid. This field is required.
  • End Date: The date the coupon expires. This field is required.
  • Minimum Order: The minimum spend amount required to use the coupon. This field is optional.
  • Maximum Usage Limit: The total number of times the coupon can be used. This field is optional.
  • Publish Instantly: A checkbox to make the coupon active and usable immediately. This field is optional.
