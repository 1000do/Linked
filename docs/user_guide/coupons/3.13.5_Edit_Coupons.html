3.13.5 Edit Coupons

The purpose of this workflow is to allow the Admin to modify the settings (End Date, Usage Limit, Active Status) of an existing discount coupon.

Execution steps:

Step 1: The Admin accesses the Manage Coupons page.

Step 2: The Admin clicks the Edit button next to a specific coupon to open the Edit Coupon modal.

Step 3: The Admin inputs information to modify the allowed fields:

  • End Date: The new expiration date for the coupon. This field is optional.
  • Maximum Usage Limit: The new total number of times the coupon can be used. This field is optional.
  • Publish Instantly: A checkbox to toggle the coupon's active status. This field is optional.
