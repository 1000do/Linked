3.13.6 Delete Coupons

The purpose of this workflow is to allow the Admin to permanently delete a discount coupon from the system.

Execution steps:

Step 1: The Admin accesses the Manage Coupons page.

Step 2: The Admin clicks the Delete button next to a specific coupon to open the Delete Coupon confirmation modal.
