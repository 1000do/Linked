3.10.12 Publish Courses

The purpose of this workflow is to allow the Instructor to submit a draft or rejected course for review and publication.

Execution steps:

Step 1: At the Course Editor page, the Instructor clicks the Submit for Review button to open the Submit for review? confirmation dialog.

(Insert a screenshot of the Submit for review? dialog here, highlighting or numbering the Yes, submit it! in red)

Figure 3.10.12.1. Publish Courses in Course Editor page

Step 2: The Instructor reviews the confirmation message.

Step 3: The Instructor clicks the Yes, submit it! button.

Step 4: After the course goes through the moderation process, the Instructor receives a Course Moderation Result notification:

  • Course Approved: The notification contains a link to the published Course Details page.
  • Course Rejected: The notification contains the rejection reason and a link back to the Course Editor page.

Step 5: The Instructor clicks the link in the notification and performs the subsequent actions:

  • If Approved: The Instructor views the published course page.
  • If Rejected: The Instructor edits the course content based on the feedback and repeats this workflow to resubmit the course.
