3.15.2 View Cart items

The purpose of this workflow is to allow the User / Instructor to quickly preview their selected courses via the header cart dropdown and navigate to the full shopping cart page.

Execution steps:

Step 1: The user / instructor accesses any page displaying the navigation bar header.

Step 2: The user / instructor clicks the shopping cart icon button in the navigation bar header to open the "Shopping Cart" mini-dropdown list.

Step 3: The user / instructor reviews the items in the mini-cart dropdown and selects a navigation option:

  • Cart Item Preview: Displays the thumbnail, course title, and price for each course currently added to the shopping cart.
  • View All: Navigates directly to the full My Shopping Cart page to view complete item details and apply promotional coupons.
  • Go to Cart: A primary button at the bottom of the dropdown that also navigates the user / instructor to the full My Shopping Cart page.
