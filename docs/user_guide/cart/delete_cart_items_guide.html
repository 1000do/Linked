3.15.3 Delete cart items

The purpose of this workflow is to allow the User / Instructor to remove an unwanted course from their shopping cart, automatically recalculating the remaining order summary.

Execution steps:

Step 1: The user / instructor accesses the My Shopping Cart page.

Step 2: The user / instructor clicks the delete icon button next to the target course item in the cart list to open the "Remove from cart?" confirmation dialog.

Step 3: The user / instructor reviews the confirmation prompt and selects an action:

  • Confirmation Message: Displays the verification prompt: "Are you sure you want to remove this course from your cart?".
  • Remove: Confirms the deletion, permanently removing the selected course from the shopping cart and recalculating the total price.
  • Cancel: Closes the confirmation dialog without removing the course from the cart.
