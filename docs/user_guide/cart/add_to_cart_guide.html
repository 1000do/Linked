3.15.1 Add to cart

The purpose of this workflow is to allow the User / Instructor to add a published course to their shopping cart to purchase it in a single checkout transaction.

Execution steps:

Step 1: The user / instructor accesses the Course Marketplace home page.

Step 2: The user / instructor clicks the shopping cart icon button on a course card to open the "Added Successfully!" confirmation modal.

Step 3: The user / instructor reviews the confirmation prompt and selects an option:

  • Confirmation Message: Displays the notification prompt: "The course has been added to your cart.".
  • Go to Cart: Navigates directly to the My Shopping Cart page to review cart items and proceed to checkout.
  • Continue Browsing: Closes the confirmation modal and keeps the user / instructor on the current page to continue exploring courses.
