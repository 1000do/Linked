3.20.2 Setup payout

The purpose of this workflow is to allow an approved instructor to link their financial profile with Stripe Connect to receive direct earned course purchase commissions and unlock premium course creation.

Execution steps:

Step 1: The approved instructor accesses the Instructor Dashboard / Application Status page after application approval.

Step 2: The approved instructor reviews their current application and financial onboarding status:

  • Application Details: Read-only. Displays the professional title and areas of expertise submitted during onboarding.
  • Application Status Tracker: Read-only. Displays the onboarding progress stepper indicating completion of application submission, administrative approval, and Stripe payout configuration.
  • Monetization Prompt Banner: Read-only. Displays a promotional notice informing the approved instructor that connecting Stripe enables selling paid premium courses and receiving 70% revenue splits.
  • Stripe Configuration Card: Read-only. Once onboarding is initiated or completed, displays the current onboarding status badge (e.g., Active or Pending), Payouts status (e.g., Enabled or Disabled), and Charges status (e.g., Enabled or Disabled). If status is Active, a Manage Stripe & Bank card button is displayed to access external Stripe settings.
