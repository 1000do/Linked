3.6.3 Mark As Read

The purpose of this workflow is to allow the user or instructor to update unread notifications to read status, either individually on specific notification cards or globally for all unread notifications at once.

Execution steps:

Step 1: The user / instructor accesses the Notifications page.

Step 2: The user / instructor identifies unread notifications in the list, which are highlighted with a solid background and a green unread indicator dot, and selects a marking method:

  • Individual Mark as Read (Check Circle Icon): Hover over an unread notification card in the list to reveal the action buttons on the right side, which includes the check circle icon button (done_all) labeled "Mark as read". Clicking this button marks that specific notification as read immediately in the system database.
  • Auto-mark via Modal Detail: Click directly anywhere on an unread notification card to open the Notification Details modal dialog. Opening the detail view automatically marks the notification as read without requiring a separate button click.
  • Mark All as Read Button: Locate the Mark All as Read button at the top right header of the page (next to the "My Notifications" title). Clicking this button triggers a system update that marks all unread notifications across the user's entire history as read simultaneously.
