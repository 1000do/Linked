3.6.5 View Notification List

The purpose of this workflow is to allow the staff or admin to view and monitor the comprehensive system notifications log table, categorize notifications by recipient role tabs, and browse historical broadcast records.

Execution steps:

Step 1: The staff / admin accesses the System Notifications page via the administration navigation menu.

Step 2: The staff / admin inspects the header bar and top navigation tabs of the page, which displays the Create Notification button and the recipient role filter tabs.

Step 3: The staff / admin reviews the notifications table and selects role tab categories or navigation controls:

  • All Notifications / Students / Instructors / Staff & Admin: Click any of these role tab buttons at the top of the table (default is "All Notifications") to dynamically filter the log and display notifications addressed to specific user role groups.
  • Recipient Column: Displays the full name of the recipient (e.g., "Truong Hung") and their registered email address (or displays "System Broadcast" and "all-users@system.com" for system-wide broadcasts).
  • Message Content Column: Displays a title preview (up to 100 characters) and a detailed message body preview for each notification record.
  • Timestamp Column: Displays the exact date and time when the notification was dispatched or generated (formatted as MM/DD/YYYY, HH:MM).
  • Status Column: Displays a status badge indicating whether the notification has been read by the recipient (grey dot with "Read") or remains unread (green dot with "Unread").
