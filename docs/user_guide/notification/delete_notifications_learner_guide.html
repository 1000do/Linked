3.6.4 Delete Notifications

The purpose of this workflow is to allow the user or instructor to permanently delete specific notifications from their personal notification history.

Execution steps:

Step 1: The user / instructor accesses the Notifications page.

Step 2: The user / instructor hovers the mouse cursor over any notification card in the list to reveal the action controls on the right side of the card.

Step 3: The user / instructor reviews the deletion control and confirmation prompt:

  • Delete Button (Trash Icon): A red button with a trash bin icon (delete) displayed on the right side of the notification card. Clicking this button initiates the deletion process for that specific notification record.
  • Confirm Deletion Dialog: Upon clicking the delete button, a confirmation popup appears with the title "Confirm Deletion" and the message "Are you sure you want to delete this notification?". It presents two interactive options: a red Delete confirmation button and a grey Cancel button.
