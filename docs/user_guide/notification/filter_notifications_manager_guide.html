3.6.10 Filter Notifications

The purpose of this workflow is to allow the staff or admin to filter the system notifications log by recipient user roles and read/unread status.

Execution steps:

Step 1: The staff / admin accesses the System Notifications page.

Step 2: The staff / admin locates the role filter tabs and the status filter dropdown menu in the control bar.

Step 3: The staff / admin selects role and status filter criteria to narrow down the notifications list:

  • Role Filter Tabs ("All Notifications", "Students", "Instructors", "Staff & Admin"): Click any role tab button above the control bar to display only notifications dispatched to recipients belonging to that specific role category. You can switch between tabs at any time.
  • Status Filter Dropdown ("All Statuses", "Unread", "Read"): Select an option from this dropdown menu (default is "All Statuses") to filter the table by read state. Selecting "Unread" displays only notifications that have not been viewed by recipients, while "Read" displays viewed notifications.
  • Combined Filtering: Role tab selections and status dropdown selections operate together in real time, allowing the staff/admin to view specific intersections (e.g., selecting the "Instructors" tab and the "Unread" status option simultaneously).
  • Reset Button: Click this button (labeled with a filter off icon) to clear all active status filters, search queries, and sorting selections, resetting the view back to "All Notifications" and "All Statuses".
