3.6.7 View Notification Detail

The purpose of this workflow is to allow the staff or admin to inspect the comprehensive details of any dispatched system notification, including recipient identity, full message content, action links, and read status.

Execution steps:

Step 1: The staff / admin accesses the System Notifications page.

Step 2: The staff / admin clicks on any notification row in the data table to open the Notification Details modal dialog.

Step 3: The staff / admin inspects the information displayed in the Notification Details modal:

  • Recipient: Displays the recipient's full name and email address (or "System Broadcast (all-users@system.com)" for system-wide broadcasts).
  • Title: Displays the complete, unclipped title of the notification message.
  • Content: Displays the full text body of the notification inside a styled content box.
  • Action Link (Optional): Displays a clickable URL anchor link if an optional link action (such as `/Course/Details/123` or an external URL) was attached when the notification was created. Clicking this link opens the target page in a new browser tab.
  • Created at Timestamp: Displays the exact creation date and time stamp at the bottom left of the modal footer.
  • Status Badge: Displays the current read status badge ("Read" or "Unread") at the bottom right of the modal footer. Note: If a staff member views a notification specifically addressed to their own user account, opening the modal automatically marks it as read in the database.
