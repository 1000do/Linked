3.6.1 View Notification list

The purpose of this workflow is to allow the user or instructor to view a list of system, course, or payment notifications, search by keyword, filter by read status, and sort the notification history.

Execution steps:

Step 1: The user / instructor accesses the Notifications page by clicking the notifications bell icon in the navigation bar header and selecting the View All link (or by clicking the Notifications link in the sidebar navigation menu for instructors).

Step 2: The user / instructor inspects the top header bar of the page, which displays the overall page title, an Online status badge, and the Mark All as Read button.

Step 3: The user / instructor reviews the notification list and selects filtering, sorting, or search options in the control bar:

  • Search by title or content...: Enter a keyword in this search input box to dynamically filter the list of notifications by title or message content.
  • All Statuses / Unread / Read: Select an option from this status filter dropdown menu (default is "All Statuses") to display all notifications or filter by unread and read states.
  • Newest First / Oldest First / Title (A-Z): Select an option from this sort dropdown menu (default is "Newest First") to organize the notification list by creation timestamp or alphabetical order.
  • Reset: Click this button to clear the search input text and reset the status filter and sort dropdowns back to their default values ("All Statuses" and "Newest First").
  • Mark All as Read: Click this button at the top of the page to mark all unread notifications in the list as read simultaneously.
  • Notification Card: Displays the notification type tag pill (e.g., "System"), an unread indicator dot (if unread), title, message preview, timestamp, and optional View Details action link. For unread items, a check circle icon button is displayed on hover to mark that individual notification as read. A delete icon button is also available on hover to remove the notification from the list.
