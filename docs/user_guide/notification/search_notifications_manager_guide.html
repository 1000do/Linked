3.6.8 Search Notifications

The purpose of this workflow is to allow the staff or admin to dynamically search and filter the system notifications log by keywords matching recipient names, email addresses, message titles, or content bodies.

Execution steps:

Step 1: The staff / admin accesses the System Notifications page.

Step 2: The staff / admin locates the search bar at the top left of the table controls bar (labeled "Search by recipient, title, content...").

Step 3: The staff / admin inputs text into the search bar and utilizes the search controls:

  • Search Input Box ("Search by recipient, title, content..."): Enter any alphanumeric keyword, recipient name, email substring, or message title/content text into this input field. The system filters the table in real time as characters are typed, displaying only matching records while preserving any active role tab or sorting selections.
  • Clear Search Text: Delete or backspace all text from the search input box to remove the keyword filter and restore the full list of notifications.
  • No Matching Results Indicator: If no records match the entered keyword, the table displays an empty state box showing an inbox icon and the message "No notifications found matching your filters".
