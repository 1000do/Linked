3.6.9 Sort Notifications

The purpose of this workflow is to allow the staff or admin to reorder the system notifications log table by creation timestamp, alphabetical title order, or recipient name order.

Execution steps:

Step 1: The staff / admin accesses the System Notifications page.

Step 2: The staff / admin locates the sort dropdown menu in the control bar above the data table.

Step 3: The staff / admin clicks the sort dropdown menu and selects a sorting criteria:

  • Newest First: This is the default sorting option. It orders notifications chronologically from the most recently created or dispatched records to the oldest.
  • Oldest First: Orders notifications chronologically from the earliest created records to the newest.
  • Title (A - Z): Sorts notifications alphabetically in ascending order (A to Z) based on the message title text.
  • Title (Z - A): Sorts notifications alphabetically in descending order (Z to A) based on the message title text.
  • Recipient (A - Z): Sorts notifications alphabetically in ascending order based on the recipient's full name (or "System Broadcast").
  • Recipient (Z - A): Sorts notifications alphabetically in descending order based on the recipient's full name.
