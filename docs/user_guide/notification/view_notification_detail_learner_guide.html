3.6.2 View Notification Detail

The purpose of this workflow is to allow the user or instructor to view the complete message content, timestamp, and associated action link of a specific notification in a modal dialog.

Execution steps:

Step 1: The user / instructor accesses the Notifications page.

Step 2: The user / instructor clicks on any Notification Card row in the list to open the Notification Details modal dialog.

Step 3: The user / instructor reviews the information presented in the Notification Details modal:

  • Title: Displays the full message title of the notification (e.g., "Welcome to Course Marketplace!").
  • Content: Displays the complete, detailed message body of the notification inside a styled content box.
  • Timestamp: Displays a schedule clock icon and the exact date and time when the notification was created (e.g., "10:30 25/07/2026").
  • View Details Link (Optional): Displays a primary button labeled View Details with an external link icon if the notification contains a specific URL or system redirect action. Clicking this button navigates the user/instructor directly to the target course or system page.
