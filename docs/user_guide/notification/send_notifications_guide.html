3.6.6 Send Notifications

The purpose of this workflow is to allow Staff and Admin members to compose and send system notifications either to specific users or broadcasted to all users.

Execution steps:

Step 1: Access the System Notifications page.

Step 2: The staff/admin clicks the Create Notification button to open the "Compose New Notification" modal dialog.

Step 3: The staff/admin inputs information / selects actions:

  • Recipient Group: Select the intended target group. Options include "Specific User (Email)" or "Broadcast (All Users)".
  • Recipient Email(s): If "Specific User (Email)" is selected, type the recipient's email address in the tag box to add it as a tag pill. Autocomplete suggestions will appear for matching registered emails. You can add multiple emails.
  • Message Title: Enter the notification title (maximum 255 characters).
  • Message Content: Enter the detailed notification message.
  • Link Action (Optional): Enter an optional URL or route (e.g., /Course/Details/123) for the action link.
