3.9.8 Send Messages

The purpose of this workflow is to allow staff and admin members to send real-time text responses, support guidance, and file attachments in active support or moderation chat sessions.

Execution steps:

Step 1: The staff/admin accesses the Chat Management page and selects an active conversation or accepted support session from the sidebar.

Step 2: The staff/admin clicks the message input area at the bottom of the chat panel to begin composing a response.

Step 3: The staff/admin inputs information / selects actions:

  • attach_file: Click this paperclip icon button to browse and attach a file or instructional document (up to 10MB) to the message. Selected files appear in the attachment preview tray where individual items can be removed or all items cleared using the "Clear all" link.
  • Type a message...: Enter the support response or moderation message in this text area. The input field adjusts vertically as multi-line text is entered.
