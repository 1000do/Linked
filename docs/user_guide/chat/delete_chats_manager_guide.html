3.9.7 Delete Chats

The purpose of this workflow is to allow staff and admin members to clear the message history of an active support or moderation conversation from their view.

Execution steps:

Step 1: The staff/admin accesses the Chat Management page and opens an active conversation from the sidebar.

Step 2: The staff/admin clicks the delete icon button (trash bin icon) in the conversation header to open the "Confirm Clear Chat" modal dialog.

Step 3: The staff/admin reviews the confirmation prompt and selects an action:

  • Confirmation Message: Displays the warning prompt: "Are you sure you want to clear this chat history? This cannot be undone.".
  • Clear: Confirms the action, clearing the message viewport and setting the cleared timestamp for the staff/admin while preserving the history for the partner participant.
  • Cancel: Closes the confirmation dialog without clearing the chat history.
