3.9.9 View Chat History

The purpose of this workflow is to allow staff and admin members to review message transcripts in active support sessions, inspect moderation conversations tied to active user reports, and check read receipts.

Execution steps:

Step 1: The staff/admin accesses the Chat Management page under the Admin Panel dashboard.

Step 2: The staff/admin clicks on a target conversation card in the sidebar (or an active moderation chat linked to a user report) to open the chat room.

Step 3: The staff/admin reviews the conversation transcript and available details:

  • Header Details: Displays the user's avatar, display name, and online status indicator ("Online" or "Offline").
  • Message Viewport: Displays the full transcript of messages sent after any prior clear action, showing sender role frames (Admin, Staff, Instructor, or Learner), timestamps, file attachments, and delivery/read ticks.
  • Scroll Viewport: Scroll up or down within the message list to inspect past correspondence or verify evidence for reported content violations.
