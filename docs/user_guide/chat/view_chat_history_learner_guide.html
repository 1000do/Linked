3.9.4 View Chat History

The purpose of this workflow is to allow the user or instructor to review previous message history within a conversation, check read receipts, and monitor online status indicators.

Execution steps:

Step 1: The user or instructor accesses the Messages page.

Step 2: The user or instructor clicks on a target conversation card in the Chats sidebar to open the chat room.

Step 3: The user or instructor reviews the conversation details and available actions:

  • Header Info: Displays the partner's avatar, display name, and real-time status indicator ("Online" in green or "Offline" in grey).
  • Message Viewport: Displays the chronological list of sent and received messages, including timestamps, file attachments (clickable thumbnails for images or downloadable links for documents), and read receipts (double ticks indicating delivery and read status).
  • Scroll Viewport: Scroll up within the message viewport to inspect historical messages sent and received earlier in the conversation.
