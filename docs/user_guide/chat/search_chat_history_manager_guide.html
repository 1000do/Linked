3.9.10 Search Chat History

The purpose of this workflow is to allow staff and admin members to search and filter active support sessions and moderation conversations by username or message keyword.

Execution steps:

Step 1: The staff/admin accesses the Chat Management page under the Admin Panel dashboard.

Step 2: The staff/admin clicks the Search users... input box located at the top of the chat sidebar.

Step 3: The staff/admin inputs information / selects actions:

  • Search users...: Enter a username, email snippet, or conversation keyword into this search field. The system debounces the query by 300ms and filters the sidebar to display only matching conversations.
  • Clear Search: Delete or clear the text from the search box to restore the complete list of active support and moderation conversations.
