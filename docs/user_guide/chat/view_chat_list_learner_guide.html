3.9.1 View Chat List

The purpose of this workflow is to allow the user or instructor to view their list of active conversations, filter by unread status, and sort the conversation list.

Execution steps:

Step 1: The user or instructor accesses the Messages page.

Step 2: The user or instructor selects filtering, sorting, or contact options in the chat sidebar controls:

  • Contact Staff: Click this button to send an initial support inquiry to the staff queue. Once a staff member clicks "Accept Request" on their end, an active chat room is established and both sides can begin messaging each other.
  • Search users...: Enter a partner's name or keyword in this search box to filter the list of active conversations.
  • All Messages / Unread: Select an option from this filter dropdown menu (default is "All Messages") to display all conversations or only those with unread messages.
  • Recently Active / Name (A-Z) / Unread First: Select an option from this sort dropdown menu (default is "Recently Active") to organize conversations by most recent activity, alphabetical order, or unread priority.
