3.9.5 Search Chat History

The purpose of this workflow is to allow the user or instructor to search and filter their list of active conversations by partner name or keyword.

Execution steps:

Step 1: The user or instructor accesses the Messages page.

Step 2: The user or instructor clicks the Search users... input box at the top of the chat sidebar.

Step 3: The user or instructor inputs information / selects actions:

  • Search users...: Type a partner's name or keyword into this search field. The system dynamically debounces the query by 300ms and filters the sidebar conversation list to display only matching conversations.
  • Clear Search: Clear or delete the text from the search input box to restore the default full list of active conversations.
