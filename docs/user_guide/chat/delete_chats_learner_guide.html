3.9.2 Delete Chats

The purpose of this workflow is to allow the user or instructor to clear the chat history of an active conversation from their view.

Execution steps:

Step 1: The user or instructor accesses the Messages page and opens an active conversation from the chat sidebar.

Step 2: The user or instructor clicks the delete icon button (trash bin icon) in the top right header of the active conversation to open the "Confirm Clear Chat" modal dialog.

Step 3: The user or instructor reviews the confirmation prompt and selects an action:

  • Confirmation Message: Displays the verification prompt: "Are you sure you want to clear this chat history? This cannot be undone.".
  • Clear: Confirms the action, removing the chat history from view while preserving the conversation records for the partner participant.
  • Cancel: Closes the confirmation dialog without clearing the chat history.
