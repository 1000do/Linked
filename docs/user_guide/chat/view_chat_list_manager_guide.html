3.9.6 View Chat List

The purpose of this workflow is to allow staff and admin members to view active support and moderation conversations, monitor pending user support requests, filter chats by unread status, and escalate issues by contacting the admin.

Execution steps:

Step 1: The staff/admin accesses the Chat Management page under the Admin Panel dashboard.

Step 2: The staff/admin views and interacts with the chat list sidebar controls and pending requests:

  • Contact Admin (Staff only): Click this button to create a direct communication channel with the system administrator for escalation or administrative assistance.
  • Pending Requests (Staff / Admin): Displays the queue of incoming user support requests waiting for assistance, showing the user's name, timestamp, message preview, and an "Accept Request" button.
  • Search users...: Enter a username or keyword into this input box to filter the list of active conversations.
  • All Messages / Unread: Select from this filter dropdown menu to display all active conversations or only those with unread messages.
  • Recently Active / Name (A-Z) / Unread First: Select from this sort dropdown menu to organize the conversation list by recent activity, alphabetical order, or unread priority.
  • Conversation Card: Click on any active conversation card in the sidebar list to select and open that chat room.
