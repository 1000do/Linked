3.9.3 Send Messages

The purpose of this workflow is to allow the user or instructor to compose and send real-time text messages and file attachments in an active conversation.

Execution steps:

Step 1: The user or instructor accesses the Messages page and selects an active conversation from the chat sidebar.

Step 2: The user or instructor clicks the message input area at the bottom of the chat panel to begin composing a message.

Step 3: The user or instructor inputs information / selects actions:

  • attach_file: Click this paperclip icon button to browse and attach a file (such as an image or document up to 10MB) to the message. Selected files appear in an attachment preview tray above the input area where individual items can be removed or all items cleared using the "Clear all" link.
  • Type a message...: Enter the desired text message in this input field. The text area expands dynamically as multi-line content is typed.
