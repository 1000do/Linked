3.12.2 Update Personal Info

The purpose of this workflow is to allow the Account Owner to update their personal details and profile information.

Execution steps:

Step 1: The Account Owner accesses the Edit Profile page.

Step 2: The Account Owner inputs information:

  • Avatar Photo: An image file (PNG, JPG, max 2MB) to use as the profile picture. This field is optional.
  • First & Middle Name: The first and middle name of the account owner. This field is required.
  • Last Name: The last name of the account owner. This field is required.
  • Username (Cannot Change): The unique username. This field is read-only.
  • Email Address: The email address associated with the account. This field is required (read-only for Google accounts).
  • Phone Number: The 10-11 digit phone number. This field is required.
  • Date of Birth: The date of birth. This field is required.
  • Bio Description: A brief description of experience and interests. This field is optional.
  • Professional Title: The professional title (visible to Instructors only). This field is optional.
  • Expertise Area: Areas of expertise separated by commas (visible to Instructors only). This field is optional.
  • LinkedIn URL: The LinkedIn profile link (visible to Instructors only). This field is optional.
  • YouTube URL: The YouTube channel link (visible to Instructors only). This field is optional.
  • Facebook URL: The Facebook profile link (visible to Instructors only). This field is optional.
