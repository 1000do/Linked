3.12.11 Search Accounts

The purpose of this workflow is to allow the Admin to search for specific accounts by entering a keyword that matches the account's name, email, or phone number.

Execution steps:

Step 1: The Admin accesses the Manage Accounts page.

Step 2: The Admin inputs information:

  • Search Keyword: The keyword to search for matching accounts by name, email, or phone. This field is required to perform a search.
