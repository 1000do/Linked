3.12.8 Update Accounts

The purpose of this workflow is to allow the Admin to update profile details, change status, and reset the password of an existing Staff account.

Execution steps:

Step 1: The Admin accesses the Manage Accounts page.

Step 2: The Admin clicks the Edit button next to a specific staff account to open the Modify Staff Account modal.

Step 3: The Admin inputs information:

  • Display Name: The full name of the staff account. This field is required.
  • New Password: The new password for the staff account (leave empty to keep current). This field is optional.
  • Contact Number: The contact phone number for the staff account. This field is optional.
  • Administrative Status: The status of the account (Active or Banned). This field is required.
