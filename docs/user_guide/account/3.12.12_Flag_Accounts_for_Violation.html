3.12.12 Flag Accounts for Violation

The purpose of this workflow is to allow the Admin to flag a user account for a policy violation. Accounts accumulating 3 flags are automatically banned for 30 days.

Execution steps:

Step 1: The Admin accesses the Manage Accounts page.

Step 2: The Admin clicks the Flag Account button next to a specific account to open the Flag Account modal.

Step 3: The Admin inputs information:

  • Reason for flagging this account: A detailed description of the policy violation. This field is required.
