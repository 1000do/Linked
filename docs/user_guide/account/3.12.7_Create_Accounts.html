3.12.7 Create Accounts

The purpose of this workflow is to allow the Admin to provision a new Staff account within the system.

Execution steps:

Step 1: The Admin accesses the Manage Accounts page.

Step 2: The Admin clicks the Add Staff Member button to open the Provision New Staff Account modal.

Step 3: The Admin inputs information:

  • Username: The username of the new staff account. This field is required.
  • Display Name: The full name of the staff member. This field is required.
  • Temporary Password: The initial password for the staff account (minimum 6 characters). This field is required.
  • Contact Number: The contact phone number for the staff account. This field is optional.
