3.19.2 Pay for a gift

The purpose of this workflow is to allow the User to review gift card details and enter payment card information to securely purchase a gifted course.

Execution steps:

Step 1: The user accesses the Secure Gift Checkout page after configuring the gift details.

Step 2: The user reviews the Gift Card Details summary and inputs information / selects actions:

  • Billing Contact Email: Read-only. Displays the authenticated user's registered account email address.
  • Card Number: Required. Enter a valid credit or debit card number (VISA, MasterCard, or AMEX).
  • Expiry Date: Required. Enter the card expiration date in MM/YY format.
  • CVC: Required. Enter the card security code.
  • Cardholder Name: Required. Enter the full name of the cardholder as displayed on the payment card.
  • Country or Region: Required. Select the billing country or region from the dropdown list (e.g., Vietnam).
