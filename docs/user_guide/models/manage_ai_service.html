3.18.2 Add AI Model

The purpose of this workflow is to allow the Admin to add a new AI model to the system.

Execution steps:

Step 1: At the AI Service Configuration page, the Admin clicks the Add AI Model button to open the Register New AI Model modal.

(Insert a screenshot of the Register New AI Model here, highlighting or numbering the Add Model in red)

Figure 3.18.2.1. Add AI Model in AI Service Configuration page

Step 2: The Admin inputs information / selects actions:

  • Model Name: The name of the AI model. Required.
  • Model Version: The version of the AI model. Required.
  • Model Path: The path or endpoint for the AI model. Required.
  • Provider: The provider of the AI model. Required.
  • Model Type: The type of the model. Required.
  • Process Type: The type of content processed. Required.
  • Status Active: Toggle to set the model as active or inactive.
  • Description: A brief description of the model. Required.

Step 3: The Admin clicks the Add Model button.

Execution steps:

Step 2: The Admin inputs information / selects actions:

  • Spam Confidence: The threshold value for spam detection. Required.
  • Toxicity Confidence: The threshold value for toxicity detection. Required.
  • Similarity Score: The threshold value for content similarity. Required.
