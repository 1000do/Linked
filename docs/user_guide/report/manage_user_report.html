3.7.1 Report A Course Review

The purpose of this workflow is to allow the User or Instructor (must be authenticated) to report a course review for policy violations.

Execution steps:

Step 1: The User or Instructor clicks on a course from the search results to access the Course Details page.

Figure 3.7.1.1. Course search result

Step 2: The User or Instructor hovers on the course review to see the three-dot icon and clicks it to show the hidden Report button.

Figure 3.7.1.2. Report button on course review

Step 3: The User or Instructor clicks the button to open the report review modal.

Step 4: The User or Instructor inputs information / selects actions:

  • Violation Reason: Select a violation reason from the dropdown.
  • Description: Input an optional description of the violation.

Figure 3.7.1.3. Report Review modal

Step 5: The User or Instructor clicks the button.


3.7.2 Report A Lesson Review

The purpose of this workflow is to allow the User or Instructor (must be authenticated) to report a lesson review for policy violations.

Execution steps:

Step 1: The User or Instructor clicks the button on the Course Details page to access the Course Learning page.

Figure 3.7.2.1. Access Course Learning page from Course Details page

Step 2: The User or Instructor clicks on the Reviews tab to see the review list.

Figure 3.7.2.2. Reviews tab

Step 3: The User or Instructor hovers on the lesson review to see the three-dot icon and clicks it to show the hidden Report button.

Step 4: The User or Instructor clicks the button to open the report review modal.

Step 5: The User or Instructor inputs information / selects actions:

  • Violation Reason: Select a violation reason from the dropdown.
  • Description: Input an optional description of the violation.

Figure 3.7.2.3. Report Review modal

Step 6: The User or Instructor clicks the button.


3.7.3 Report A Course

The purpose of this workflow is to allow the User or Instructor (must be enrolled in the course) to report a course for policy violations.

Execution steps:

Step 1: At the Course Details page, the User or Instructor clicks the button to open the report course modal.

Figure 3.7.3.1. Report a course in Course Details page

Step 2: The User or Instructor inputs information / selects actions:

  • Reason: Select a violation reason from the dropdown.
  • Description: Input a detailed description of the violation with at least 20 characters.
  • Add another reason: Click this button to add another reason dropdown and description field.

Step 3: The User or Instructor clicks the button.


3.7.4 View List of User Reports

The purpose of this workflow is to allow the Staff or Admin to view a list of user reports in the system.

Execution steps:

Step 1: The Staff or Admin accesses the Dashboard and clicks the Report Center menu item to open the Report Center page.

Figure 3.7.4.1. Report Center page

Step 2: The Staff or Admin clicks the Course Reports or Review Reports main tabs to switch between course reports and review reports.

Step 3: The Staff or Admin clicks the Course Reviews or Lesson Reviews subtabs (under Review Reports) to switch between course reviews and lesson reviews.


3.7.5 View Report Detail

The purpose of this workflow is to allow the Staff or Admin to view detailed information about a specific report, including moderation resolution details if available.

Execution steps:

Step 1: At the Report Center page, the Staff or Admin clicks directly anywhere on a report row (except the button) to open the report details modal.

Figure 3.7.5.1. View report details in Report Center page

Step 2: The Staff or Admin views the information:

  • Report Details: View the Reporter, Submitted At, Status, Reported Content, Reason, and Description.
  • Resolution Details: View the Moderator, Resolved At, and Resolution Note if the report has been resolved or rejected.

3.7.6 Filter Reports

The purpose of this workflow is to allow the Staff or Admin to filter the list of user reports by status.

Execution steps:

Step 1: At the Report Center page, the Staff or Admin clicks on the status filter dropdown.

Figure 3.7.6.1. Status filter dropdown

Step 2: The Staff or Admin selects a status criteria (e.g., Pending, Resolved, Rejected) from the status filter dropdown.


3.7.7 Resolve Report

The purpose of this workflow is to allow the Staff or Admin to moderate and resolve a pending user report.

Execution steps:

Step 1: At the Report Center page, the Staff or Admin clicks the button on a pending report row to open the moderation modal.

Figure 3.7.7.1. Resolve a report in Report Center page

Step 2: The Staff or Admin inputs information / selects actions:

  • Status: Select a moderation status (e.g., Accept Report, Dismiss Report, Escalate to Senior Admin) from the dropdown.
  • Moderation Details: Input a note detailing the moderation decision.
  • Flag Course / Remove content: Check the checkbox to apply a penalty to the reported content, and confirm the action on the secondary confirmation popup. This is only available when the Accept Report status is selected.

Step 3: The Staff or Admin clicks the button.
