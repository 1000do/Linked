3.8.2 View Instructor Payouts

The purpose of this workflow is to allow the Admin to view and manage the payout records and statuses for instructors on the platform.

Execution steps:

Step 1: The Admin accesses the Admin Finance dashboard page and clicks the Instructor Payouts tab.

Step 2: The Admin reviews the payouts table displayed on the page, which includes the following information:

  • Instructor Name: The name of the instructor receiving the payout.
  • Tx ID: The transaction identifier.
  • Payout Share: The calculated monetary share transferred to the instructor.
  • Split Rate: The percentage rate applied for the revenue split.
  • Stripe Status: The current payout status recorded in Stripe.
  • Action: Available actions for the specific payout record.
