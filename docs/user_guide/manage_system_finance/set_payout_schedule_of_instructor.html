3.8.8 Set Payout Schedule of Instructor

The purpose of this workflow is to allow the Admin to configure the days of the month when automatic bulk payouts are triggered for instructors. The configured days are saved in the system configurations.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin locates the Auto Payout Scheduler setting card.

Step 3: The Admin inputs information / selects actions:

  • Trigger Day(s): An input field to enter a single day or a comma-separated list of days of the month (must be between 15 and 20) when payouts will trigger.

Step 4: The Admin clicks the Save Config button to open the Confirm Payout Schedule dialog.
