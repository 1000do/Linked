3.8.9 Withdraw Funds

The purpose of this workflow is to allow the Admin to manually transfer accumulated platform net profit from the Stripe available balance directly into the platform's corporate bank account.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin locates the Withdraw Funds to Bank settings card.

Step 3: The Admin inputs information / selects actions:

  • Amount ($): An input field to enter the target payout amount to withdraw from the available balance.
  • Description (Optional): An input field to enter an optional transfer explanation.

Step 4: The Admin clicks the Withdraw Now button to open the Confirm Withdrawal dialog.
