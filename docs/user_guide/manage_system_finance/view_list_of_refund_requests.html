3.8.4 View List of Refund Requests

The purpose of this workflow is to allow the Admin to view and monitor the list of pending refund requests submitted by students.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin clicks the Refund Requests tab.

Step 3: The Admin reviews the list of pending refund requests displayed on the page, which includes the following information:

  • Transaction Details: Information about the original purchase transaction.
  • Course Title: The title of the course associated with the refund request.
  • Student Name: The name of the student who submitted the request.
  • Refund Reason: The reason provided by the student for requesting a refund.
