3.16.1 View System Transaction List

The purpose of this workflow is to allow the Admin to display a master list of all transaction orders across the platform.

Execution steps:

Step 1: The Admin clicks the Revenue Dashboard menu item to open the Financial Management dashboard page.

Step 2: The Admin clicks the Transaction History tab.

Step 3: The system displays a master list of transactions including Stripe Tx ID, Course, Purchased By, Instructor, Amount, Date, and Status.
