3.8.6 Reject Refund Request

The purpose of this workflow is to allow the Admin to reject a student's pending refund request, which reverts the transaction status to success, retains the student's course access, and notifies the student of the decision.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin clicks the Refund Requests tab to view the list of pending refund requests.

Step 3: The Admin clicks the Reject button on a pending refund request row to open the Reject Refund dialog.

Step 4: The Admin inputs information / selects actions:

  • Rejection reason: A required text area to enter a specific reason for rejecting the refund request, which will be provided to the student.
