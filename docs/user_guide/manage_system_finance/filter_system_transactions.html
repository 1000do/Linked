3.16.3 Filter System Transactions

The purpose of this workflow is to allow the Admin to filter the transaction list by payment status, month, or year.

Execution steps:

Step 1: The Admin clicks the Revenue Dashboard menu item to open the Financial Management dashboard page.

Step 2: The Admin clicks the Transaction History tab.

Step 3: The Admin inputs information / selects actions:

  • Month/Year Dropdowns: Optional. Select a specific month and year at the top filter bar to view transactions for that period.
  • Status: Optional. A dropdown menu to select the transaction status (e.g., All Statuses, Succeeded, Refund Pending, Refunded, Failed).
