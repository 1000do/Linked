3.8.3 View Funds Withdrawal History

The purpose of this workflow is to allow the Admin to view the historical log of platform funds withdrawn to the connected bank account.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin clicks the Manager Bank Withdrawals tab.

Step 3: The Admin reviews the withdrawals table displayed on the page, which includes the following information:

  • Reference ID: The unique identifier for the withdrawal transaction.
  • Amount: The total monetary amount of funds withdrawn.
  • Status: The current status badge of the withdrawal request.
  • Initiated Date: The date and time the withdrawal was initiated.
