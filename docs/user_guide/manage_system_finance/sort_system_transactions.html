3.16.4 Sort System Transactions

The purpose of this workflow is to allow the Admin to sort transactions by date or amount.

Execution steps:

Step 1: The Admin clicks the Revenue Dashboard menu item to open the Financial Management dashboard page.

Step 2: The Admin clicks the Transaction History tab.

Step 3: The Admin inputs information / selects actions:

  • Sort By: Optional. A dropdown menu to select the sorting criteria (Date: Newest, Date: Oldest, Amount: High to Low, Amount: Low to High).
