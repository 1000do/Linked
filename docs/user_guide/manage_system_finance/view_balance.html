3.8.1 View Balance

The purpose of this workflow is to allow the Admin to view the platform's financial performance, including Course Revenue, Revenue Splits & Distributions, Stripe Gateway Balances, and the monthly financial chart.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin reviews the financial summary cards displayed on the dashboard:

  • Course Revenue: Displays Gross Revenue, Total Refunded, and Net Earnings.
  • Revenue Splits & Distributions: Displays Paid to Instructors, Escrow Funds, and Platform Net Profit.
  • Stripe Gateway Balances: Displays Stripe Balance (Available Now, In Transit) and Total Stripe Assets.
