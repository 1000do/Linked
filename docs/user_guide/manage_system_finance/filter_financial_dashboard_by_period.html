3.8.10 Filter Financial Dashboard By Period

The purpose of this workflow is to allow the Admin to filter the financial statistics, charts, and transaction balances displayed on the dashboard for a specific month and year.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin inputs information / selects actions:

  • Month: A dropdown menu to select the desired month.
  • Year: A dropdown menu to select the desired year.
