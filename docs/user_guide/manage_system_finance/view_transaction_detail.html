3.8.11 View Transaction Detail

The purpose of this workflow is to allow the Admin to view the detailed information of a specific transaction, including the buyer profile, course information, financial split figures, and any associated refund logs.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin clicks the View button next to a transaction row (in the Transaction History tab) or clicks the Details button (in the Refund Requests tab) to open the Transaction Details page.

Step 3: The Admin reviews the detailed transaction information displayed on the page, which includes the following sections:

  • Basic Information: The unique transaction identifier, creation timestamp, current status badge, and gross purchase amount.
  • Course Details: The course title, thumbnail, and associated instructor name.
  • Buyer Profile: The buyer's full name, email address, and registration details.
  • Financial Split: The breakdown calculation showing the Stripe processing fee, net price, instructor payout, and platform share.
  • Refund Logs: If a refund was requested, the panel showing the request date, student's reason, and the administrative feedback note.
