3.8.5 Approve Refund Request

The purpose of this workflow is to allow the Admin to approve a student's pending refund request, which automatically triggers a Stripe refund, reverses the instructor payout, and revokes the student's course access.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin clicks the Refund Requests tab to view the list of pending refund requests.

Step 3: The Admin clicks the Approve button on a pending refund request row to open the Approve Refund dialog.

Step 4: The Admin inputs information / selects actions:

  • Feedback note: An optional text area to enter a feedback note for the student regarding the refund approval.
