3.8.7 Set Transfer Rate

The purpose of this workflow is to allow the Admin to update the percentage of course purchase revenue allocated to instructors. This new rate is applied to all future transactions and broadcasted to onboarded instructors.

Execution steps:

Step 1: The Admin accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Admin Finance dashboard page.

Step 2: The Admin locates the Revenue Share Split Rate setting card.

Step 3: The Admin inputs information / selects actions:

  • Instructor Share (%): A numeric input field to enter the target percentage rate allocated to instructors (must be between 30 and 95).

Step 4: The Admin clicks the Save Rate button to open the Confirm Rate Change dialog.
