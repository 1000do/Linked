3.16.2 Search System Transactions

The purpose of this workflow is to allow the Admin to search transactions by keyword (course title, student name, instructor, etc.).

Execution steps:

Step 1: The Admin clicks the Revenue Dashboard menu item to open the Financial Management dashboard page.

Step 2: The Admin clicks the Transaction History tab.

Step 3: The Admin inputs information / selects actions:

  • Search Box: Optional. Enter a keyword to search for specific transactions (e.g., course title, student name, instructor).
