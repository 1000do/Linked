3.16.1 View Transaction List

The purpose of this workflow is to allow the authenticated user to view their purchase history, track payment statuses, and review transaction records.

Execution steps:

Step 1: The authenticated user accesses the Purchase History page by clicking the Purchase History link from the account settings navigation sidebar.

Step 2: The authenticated user reviews the transaction records displayed in the list and the escrow protection policy:

  • Course Details: Read-only. Displays the course thumbnail icon, course title, instructor name, and a gift badge if the course was purchased as a gift.
  • Date & ID: Read-only. Displays the unique transaction ID number (e.g., #12345) and the exact date and timestamp of the purchase.
  • Amount & Status: Read-only. Displays the total transaction cost in currency and the payment status badge (Success, Refund Pending, Refunded, or Failed).
  • 14-Day Escrow Policy: Read-only. Displays the Stripe Secure Hold notification explaining that payments are held securely in escrow for 14 days under the buyer protection policy.
  • Refund Button: Optional. Displays a conditional Refund button for successful course purchases within the 14-day escrow window that are not claimed gifts.
  • View Details Icon: Read-only. Displays an arrow icon link that navigates to the detailed financial breakdown of the transaction record.
