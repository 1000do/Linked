3.16.6 View Transaction Detail

The purpose of this workflow is to allow the authenticated user to view the full electronic invoice, payment receipt breakdown, and refund status notes for a specific transaction.

Execution steps:

Step 1: The authenticated user accesses the Purchase History page and clicks the View Details arrow icon link next to a transaction record.

Step 2: The system displays the Electronic Invoice page. The authenticated user reviews the transaction receipt and financial breakdown:

  • Refund Status Banner: Read-only. Displays conditional notification banners if the transaction is under review (showing the user's submitted refund reason), refunded (showing the approved status, revoked course access notice, user reason, and Admin response note), or rejected (showing the rejection notice, original reason, and Admin response note).
  • Invoice Header: Read-only. Displays the electronic invoice title, payment status badge (Success, Failed, Pending, Refund Pending, or Refunded), unique transaction ID number (e.g., #12345), and the exact date and timestamp of payment.
  • Customer Details: Read-only. Displays the buyer's full name and registered email address associated with the account.
  • Payment Method: Read-only. Displays the online payment gateway used to process the transaction (e.g., Paid via Stripe - Secure Online Payment).
  • Course Details: Read-only. Displays the course thumbnail image, course description title, instructor name, and line-item total price (displayed as a negative value with a minus sign if the transaction was refunded).
  • Total Summary: Read-only. Displays the detailed financial calculation including Subtotal (original course price), Discount (applied coupon code badge and discount amount deducted if a promotional code was used), and the final Total gross amount paid.
  • Back to history Link: Optional. A navigation link at the top of the page that allows the user to return to the main Purchase History transaction list.
