3.16.2 Search Transaction History

The purpose of this workflow is to allow the authenticated user to search for specific transaction records by course title keyword.

Execution steps:

Step 1: The authenticated user accesses the Purchase History page from the account settings navigation sidebar.

Step 2: The authenticated user inputs search information into the filter bar:

  • Search by course title...: Required. A text input field where the authenticated user types a keyword string matching the title of a purchased course to locate specific transaction records.
