3.16.5 Request Refund

The purpose of this workflow is to allow the authenticated user to submit a refund request for an eligible course purchase within the 14-day escrow protection period.

Execution steps:

Step 1: The authenticated user accesses the Purchase History page and clicks the Refund button next to an eligible successful transaction record.

Step 2: The system displays the Request Refund confirmation dialog popup. The authenticated user inputs information into the form:

  • Enter refund reason here...: Required. A multi-line textarea field where the authenticated user must type a specific, detailed explanation justifying the refund request for Admin review. Leaving this field empty triggers a validation alert stating "You must enter a refund reason!".
