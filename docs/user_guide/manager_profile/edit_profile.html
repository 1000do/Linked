1.1.2 Edit Profile (Manager)

The purpose of this workflow is to allow the Manager (Super Admin or Staff Support) to edit their profile information, upload a profile picture, and save the updated details to the system.

Execution steps:

Step 1: The Manager accesses the Administrative Profile page.

Step 2: The Manager clicks the Edit Profile button to open the Edit Profile Info page.

Step 3: The Manager inputs information / selects actions:

  • Profile Picture: Optional. Click the "Choose File" button to upload a new profile avatar.
  • Display Name: Required. Enter a manager nickname. Maximum limit of 255 characters.
  • Full Name: Optional. Enter the full name. Maximum limit of 255 characters.
  • Contact Number: Optional. Enter a contact phone number. Must match the standard format (e.g., +84912345678) and not exceed 50 characters.
  • Biography / About Me: Optional. Enter a brief description about the administrative role. Cannot exceed 1000 characters.
