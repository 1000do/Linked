1.1 View Profile (Manager)

The purpose of this workflow is to allow the Manager (Super Admin or Staff Support) to view their profile details, including system account information.

Execution steps:

Step 1: The Manager clicks their profile section at the bottom left of the sidebar menu.

Step 2: The system displays the Administrative Profile page showing the manager's profile details and employment system information.
