3.11.6 Filter Instructor's Transaction History

The purpose of this workflow is to allow the Instructor to filter sales transactions by status or date range.

Execution steps:

Step 1: The Instructor accesses the Learner Purchases tab on the Revenue & Payouts dashboard page.

Step 2: The Instructor inputs information / selects actions:

  • Month/Year: Dropdown menus in the top-right corner to filter by a specific period.
  • Status: A dropdown menu to select the transaction status (e.g., All Statuses, Completed, Pending, Failed).

Step 3: The Instructor clicks the Filter button.
