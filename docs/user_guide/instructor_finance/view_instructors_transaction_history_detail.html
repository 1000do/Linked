3.11.10 View Instructor's Transaction History Detail

The purpose of this workflow is to allow the Instructor to display details of the course sale transaction showing platform fee deductions and net revenue.

Execution steps:

Step 1: The Instructor accesses the Learner Purchases tab on the Revenue & Payouts dashboard page.

Step 2: The Instructor clicks the View Details button (eye icon) next to a transaction row to open the Transaction Details page.

Step 3: The system displays the detailed transaction information, including course details, gross amount, fee deductions, and net revenue.
