3.11.3 View Instructor's Transaction History

The purpose of this workflow is to allow the Instructor to view a list of recent course sales transactions.

Execution steps:

Step 1: The Instructor accesses the Dashboard and clicks the Revenue Dashboard menu item to open the Revenue & Payouts dashboard page.

Step 2: The Instructor clicks the Learner Purchases tab.

Step 3: The system displays a table of recent transactions including Date, Course / Purchaser, Net Earnings, and Status.
