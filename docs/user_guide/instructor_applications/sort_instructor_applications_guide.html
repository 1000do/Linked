3.5.8 Sort Instructor Applications

The purpose of this workflow is to allow Staff and Admin members to sort the pending instructor applications list by submission date or alphabetical order of the applicant's name.

Execution steps:

Step 1: The staff/admin accesses the Instructor Registration Requests page.

Step 2: The staff/admin clicks the Default (Oldest First) sort dropdown menu in the controls bar.

Step 3: The staff/admin inputs information / selects actions:

  • Default (Oldest First): Sorts the pending applications table by submission date in ascending order, displaying the oldest registration requests first.
  • Newest First: Sorts the pending applications table by submission date in descending order, displaying the most recent registration requests at the top.
  • Name (A - Z): Sorts the applications table alphabetically from A to Z based on the applicant's full name.
  • Name (Z - A): Sorts the applications table alphabetically in reverse order from Z to A based on the applicant's full name.
  • Reset Button: Click this button (labeled with a filter off icon) to clear all active sorting selections, search queries, and specialization filters, resetting the table order back to "Default (Oldest First)".
