3.5.5 Reject Instructor Application

The purpose of this workflow is to allow Staff and Admin members to decline a pending instructor registration application by providing a mandatory reason for rejection.

Execution steps:

Step 1: The staff/admin accesses the Instructor Registration Requests page.

Step 2: The staff/admin clicks the Reject button for a pending instructor application in the table to open the "Reject Application" modal dialog.

Step 3: The staff/admin inputs information / selects actions:

  • Reason for Rejection: Required. Enter a detailed explanation specifying why the instructor application is being declined (e.g., insufficient credentials or missing portfolio documents). Leaving this field blank will trigger a validation error ("You must enter a reason for rejection!").
  • Cancel: Closes the modal dialog without rejecting the application or saving any changes.
