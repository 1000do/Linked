3.5.2 View Instructor Applications Detail

The purpose of this workflow is to allow Staff and Admin members to inspect the detailed credentials, professional profile information, social media links, and submitted documents of an instructor applicant.

Execution steps:

Step 1: The staff/admin accesses the Instructor Registration Requests page.

Step 2: The staff/admin clicks the View Info link for a pending instructor application in the table to open the Instructor Registration Detail page.

Step 3: The staff/admin inspects information / selects actions:

  • Applicant Profile: Displays the applicant's avatar image, full name, and registered email address.
  • Professional Title: Displays the professional title or headline provided by the applicant (or indicates "No Title Provided" if omitted).
  • Specializations & Expertise: Displays category pills representing the instructor's specialized teaching areas and domains of expertise (e.g., software development, business, design).
  • Social Media Profiles: Displays external verification links for the applicant's professional profiles, including LinkedIn, YouTube, and Facebook. The staff/admin can click "Visit Profile" or "Visit Channel" to open the external profile in a new browser tab, or view "Not Provided" if the link was unsubmitted.
  • Submitted Documents: Displays clickable links for uploaded resume or portfolio files (e.g., Document #1 (.pdf)). The staff/admin can click any document link to open and review the submitted file in a new browser tab.
