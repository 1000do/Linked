3.5.4 Approve Instructor Application

The purpose of this workflow is to allow Staff and Admin members to approve a pending instructor registration application, upgrading the user's role to Instructor and publishing their status.

Execution steps:

Step 1: The staff/admin accesses the Instructor Registration Requests page.

Step 2: The staff/admin clicks the Approve button for a pending instructor application in the table to open the "Approve Application" confirmation dialog.

Step 3: The staff/admin reviews the confirmation prompt and selects an option:

  • Confirmation Message: Displays the verification prompt: "Are you absolutely sure you want to approve this instructor application?".
  • Approve: Confirms the approval, updating the applicant's status to "Approved" and promoting their account role to Instructor.
  • Cancel: Closes the confirmation dialog without making any changes to the application status.
