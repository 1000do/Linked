3.5.6 Search Instructor Applications

The purpose of this workflow is to allow Staff and Admin members to search the pending instructor applications list in real-time by applicant name, email, professional title, or expertise specialization.

Execution steps:

Step 1: The staff/admin accesses the Instructor Registration Requests page.

Step 2: The staff/admin clicks the Search by name, email, title... input field in the controls bar.

Step 3: The staff/admin inputs information / selects actions:

  • Search Query: Optional. Enter a keyword (such as an applicant's full name, email address, professional title, or teaching specialization) into the search box to filter the table rows in real-time.
  • Clear Search: Optional. Delete or clear the search query text from the input field, or click the Reset button in the controls bar, to reset the table and display all pending instructor applications.
