3.5.7 Filter Instructor Applications

The purpose of this workflow is to allow Staff and Admin members to filter the pending instructor applications list by specific teaching expertise or specialization categories.

Execution steps:

Step 1: The staff/admin accesses the Instructor Registration Requests page.

Step 2: The staff/admin clicks the All Specializations filter dropdown menu in the controls bar.

Step 3: The staff/admin inputs information / selects actions:

  • Specialization Category: Select a specific teaching domain or expertise category (e.g., software development, business, design) from the dropdown list to display only matching instructor applications in the table.
  • All Specializations: Select this default option from the dropdown list to reset the filter and display all pending instructor applications.
  • Reset Button: Click this button (labeled with a filter off icon) to clear all active specialization filters, search queries, and sorting selections, resetting the view back to default.
